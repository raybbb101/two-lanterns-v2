# ふたつの灯 v2 — Two Lanterns

絵とエフェクトをすべてピクセルアートに作り直したバージョン 2。遊び方は v1 と同じです。

二人で協力して地下迷宮を進む、ブラウザで遊べるオンライン協力アクション。
離れた場所の友達とも、**ルームコード**を伝えるだけで一緒に遊べます。

## 遊び方

| 操作 | キー |
| --- | --- |
| 移動 | W A S D |
| 攻撃（長押しで連続） | 左クリック |
| 回避（無敵） | Space / 右クリック |
| スキル | Q / E / R / C |
| 拾う・宝箱を開ける | F |
| キャラクター画面（装備・スキル習得） | Tab |
| 操作説明 / 音 | H / M |

- 一人が「ルームを作る」→ 画面右上の 5 文字のコードを相方に伝える
- 相方は「参加する」にコードを入れる（`https://…/?room=コード` のリンクでも入力済みで開けます）
- フロアの魔物を全滅させると転移陣が開く。二人で乗ると次の層へ。3 層ごとにボス
- 宝箱・敵から武器（6 種 × 5 レアリティ＋特殊効果）とスキルの巻物（7 種）がドロップ
- 倒れても相方がそばに立てば復活

## 育成

- ジョブは 5 種類（剣士・弓使い・魔導士・癒し手・影の刃）。ジョブごとにスキルツリーがあり、2 つの大分岐と、それぞれ 2 つの最終ジョブ（全部で 4 つ）から 1 つを選びます
- 武器は同じ武器種・同じレアリティを集めて合成（コモン 5 本 → アンコモン 4 本 → レア 3 本 → エピック 2 本 → レジェンド 2 本 → 神話）
- 防具は 5 か所。セットは 2 個と 4 個で効果が出ます
- 石碑のなぞなぞと光る台座を解くと報酬がもらえます

## 保存

進行状況はジョブごとに自動で保存され、同じブラウザなら続きから遊べます。タイトルの「書き出し／読み込み」で別のブラウザにも移せます。

## 魔物（v2 のオリジナル）

胞子キノコ / 大胞子キノコ / 石翼のインプ / 錆鎧 / 蝋燭の祈祷師 / ボス：苔の巨像

## ローカルで試す

ファイルが多いので、並列の読み込みに強いサーバーで開いてください。

```bash
npx serve .
```
